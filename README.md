# Bookmark Mode Switcher

ブックマークバーの中身を「普段」「開発」などのモードで丸ごと入れ替える Chrome 拡張。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」を ON にする
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

- ツールバーのアイコンを押してモードを選ぶ
- `Alt+Shift+B` で次のモードに順に切り替わる（キーは `chrome://extensions/shortcuts` で変更できる）
- バッジに現在のモード名の先頭 2 文字が出る

## 仕組み

- 「その他のブックマーク」の下に `Bookmark Modes` フォルダを作る
- 待機中のモードはここにサブフォルダとして置かれ、アクティブなモードはブックマークバーに展開される
- 中の `__active__:<名前>` という空フォルダは、今どのモードかを示す目印。消したりリネームしたりしないこと
- 切り替えは `bookmarks.move` で行う。コピーも削除もしないので、Chrome 同期とも衝突しない

## モードの追加

`Bookmark Modes` の中にフォルダを作ると、それがそのまま新しいモードになる。
